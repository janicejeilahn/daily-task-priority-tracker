# daily-task-priority-tracker
Automated daily task manager, site priority logger, and executive progress note generator.

## Cloud lead sweep

`lead_sweep/` runs the daily new-lead sweep through the Meta Graph API and Google Sheets API, so it works in a cloud session with no browser. Setup: [CLOUD_SWEEP_SETUP.md](CLOUD_SWEEP_SETUP.md). Routine prompt: [daily_lead_sweep_cloud_task.md](daily_lead_sweep_cloud_task.md).
